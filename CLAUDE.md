# RYSCore: правила проекта

Общая основа модов семьи RYS (RYScope, RYSQuests, дальше RYSPulse). modid `ryscore`, пакет `works.repka.ryscore`, NeoForge 1.21.1, позже Fabric. Автор Дмитрий (MityaYS, RepkaWorks).

Главная по кору сессия, которая ведёт RYScope (решение автора, 09.11.2026). Другие чаты кор не правят: они пишут блок «Запрос к RYSCore» (что нужно, зачем, какой контракт), автор передаёт его сюда.

## Как работать с автором

* Общаться только по-русски. Английский допустим в коде и в текстах для игроков, если автор о них просит.
* Прогресс показывать списком сверху: сделанное помечать ✅, без зачёркиваний. Законченный шаг показывать сразу и продолжать.
* Если нет уверенности в механике мода или кода Minecraft, не выдумывать: проверить (декомпиляция CFR, логи, тест в отдельном новом мире).
* Файлы на ПК не удалять, ненужное переносить в `_stale`.
* Перед текстами для игроков показывать черновик.

## Что кладём в кор

Только то, что нужно хотя бы двум модам семьи: темы и токены, рисование, виджеты, доска поверх мира, разметка текста, реестры, через которые моды находят друг друга.

Рецепты, квесты и прочая логика конкретного мода сюда не попадают. Кор не знает о модах семьи и не зависит от них.

`common/` компилируется против чистого Minecraft без API загрузчика. Код загрузчика лежит в `neoforge/`.

## Контракт

* Публичный код кора это контракт. Версия в `gradle.properties`.
* В 1.x только добавляем. Убрать или изменить сигнатуру, токен, формат файла можно только в 2.0.
* Новый токен темы обязан иметь запасной в цепочке `Theme.FALLBACK`, иначе старые темы сломаются.
* Каждый мод вкладывает кор через jarJar с диапазоном `[нужная версия,2.0.0)` и объявляет такую же обязательную зависимость. При нескольких модах загрузчик берёт самую новую вложенную версию.
* Нельзя держать классы кора внутри jar мода или копировать пакет: два мода с одним пакетом не запускаются вместе (`ResolutionException`, проверено).
* Моды семьи общаются только через интерфейсы кора, не напрямую друг с другом и не через отражение.

## Как выпустить изменение

1. Правка, новая запись в `CHANGELOG.md`, версия в `gradle.properties`.
2. `gradlew build publish`: jar попадает в `repo/`, оттуда его берут моды (`../RYSCore/repo`).
3. Поднять `ryscore_version` в модах, которым нужна новая версия.
4. Проверить RYScope автотестом, в том числе на копии сборки RepYS: `gradlew :prodtest:runAutotest -PrunDir=run-repys -Pheap=8G -Pautotest=dock`.

## Единый вид и тон

Игрок не должен видеть шов между модами. Эти правила приняты после замечаний автора.

* Цвета только через токены темы. В экранах констант нет. Исключение: фиксированные цвета значков, задуманные как различимые.
* Скругления и контуры только через `Draw` и примитивы `Theme`.
* Окно открывается сразу. Тяжёлый расчёт идёт порциями по несколько миллисекунд за кадр, внутри окна `Loading`.
* Окна не прыгают: верхний край закреплён, рост только вниз.
* Подсказок строкой внизу окна нет: значок `Draw.info` и подсказка при наведении.
* В шапке нет лишнего: не дублировать то, что и так видно.
* Несколько разделов это вкладки, а не стрелки «1/7».
* Панели обходят чужие области экрана и не перекрывают слоты.
* Макеты главнее текущего вида: образец Slate лежит в `RYScope/design/Main.dc.html`.
* Янтарный акцент только у главного действия окна и линии активной вкладки. Активная вкладка-плашка серая (`tab.active.bg`).
* Несколько разделов окна это `Theme.tabLine` со счётчиками, значки разделов это `Theme.tab`.
* Боковая панель через `Theme.sidebar`: тема сама решает, прижата ли она к краю.
* Предметы лежат на плашках слотов. Длинные сетки рисовать через `Theme.slots`, одним вызовом.
* Кнопка главного действия подписана словом («Перенести»), значок без подписи только там, где нет места.
* Наличие ингредиента показывает рамка слота (`slot.have.border`, `slot.miss.border`) и строка статуса с точкой.

Новое замечание автора о виде или поведении записывать сюда правилом, чтобы оно попало во все моды.

## Что уже в коре

| Класс | Назначение |
|---|---|
| `theme.Theme` | токены темы и примитивы: `panel, sidebar, card, plate, slot, slots, hover, button, input, tab, tabLine, chip, tooltipBox` |
| `theme.ThemeManager` | загрузка тем из `assets/<ns>/ryscore_themes/*.json`, общий выбор темы в `config/ryscore/theme.json` |
| `ui.Draw` | скругления по пикселям устройства, текст, стрелки, замок, значки `info`, `question`, `magnifier`, `cross`, `star`, `dot` |
| `ui.Loading` | индикатор расчёта внутри окна |
| `ui.Tiles` | много одинаковых ячеек за один вызов отрисовки |
| `team.TeamsApi` | команды для модов семьи, без RYSTeams каждый игрок соло |

Следующие кандидаты, когда понадобятся второму моду: доска поверх мира (сейчас `runtime/Board.java` в RYScope), разметка `[[item:…]]`, панель кнопок (`ui/Dock.java`), интерфейс «показать рецепт».
