# История RYSCore

## 1.7.5

Текст быстрее: ширина и наличие глифов кешируются по лицу шрифта (массивы для кодпоинтов ниже 0x500), вызовы в нативный шрифт уходят из горячих путей. `Draw.wrap` и `Draw.wrapLabel` копят ширину по словам, `Draw.ellipsize` меряет по символу без создания строк. Межбуквенный интервал: `Type.draw/width` и `Draw.label/labelWidth` с параметром `tracking`, строка капсом рисуется одним вызовом. `Type.resolved` открыт.

## 1.7.4

`SceneView.setScene`: смена сцены того же размера без мигания, прежняя картинка видна, пока новая строится в фоне; камера и слой сохраняются. Для перебора вариантов блоков в превью структур.

## 1.7.3

Цвет темы `state.order` и состояние `Kit.State.ORDER` (значок шестерёнки): своего нет, но недостающее можно заказать, например автокрафтом сети AE2.

## 1.7.2

`Draw.question`: знак «?» стоит по центру кружка по своей настоящей ширине, в шрифте темы и в шрифте игры.

## 1.7.1

Скругления и тени рисуются из заготовок: фигура один раз растеризуется в маленькую текстуру и выводится одним вызовом из девяти кусков. Пиксели те же, что раньше, но вместо сотен и тысяч заливок на элемент их девять, тень под окном из 28 слоёв стала одной заготовкой. API `Draw` не изменился.

`Draw.scale(g)`: пикселей экрана в единице с учётом масштаба матрицы. Текст, скругления, значки и плитки слотов растрируются под настоящий размер, поэтому не плывут на карте с зумом и в уменьшенных предпросмотрах.

## 1.7.0

Общий 3D-вид блоковых структур, пакет `scene`. `BlockScene`: неизменяемые данные, сдвиг к нулю, подсчёт блоков по предмету. `SceneView`: вращение, масштаб и показ по слоям, рисует строго внутри прямоугольника при любом масштабе и обрезке. Геометрия строится в фоне и лежит в буферах по слоям, соседние грани отсекаются, тонировка по биому равнины. Блок-сущности пока пропускаются. `Draw.isolated`: чужой код не может оставить после себя сдвинутую матрицу.

## 1.6.0

Масштаб окон семьи не зависит от GUI Scale: `ui.UiScale` (настройка Авто, 75, 100, 125, 150 %), `ui.ScaledScreen` для экранов, `UiScale.render` для HUD, `Draw.scissor` вместо `g.enableScissor` в нашем коде. `ui.WindowLayout`: окна не перекрываются. `ui.Anchors`: углы постоянных элементов и зона карты, `config/ryscore/ui.json`. Значки шевронов, ручки, карандаша, отмены, повтора, точки и половины точки. Строка с кириллицей в заголовке целиком идёт Inter 600. `Kit.tabs`: вкладки одним компонентом. `Kit.indicator`: состояние не только цветом. `ui.Numbers`: большие числа с приставками.

## 1.5.2

`ui.Scroller`: плавная прокрутка с лёгким упором у края. `Theme.tabLine` рисует линию во всех темах, кроме ванильной: вкладка раздела не должна быть похожа на кнопку. Значки `PLUS` и `PIN`.

## 1.5.1

Знаки, которых нет в шрифте (галочка, крестик, звезда, стрелки), в тексте рисуются значками. Страница шрифта загружается только в изменённой области. Надпись, на которой сбросился атлас, перерисовывается заново, а не показывает чужие глифы.

## 1.5.0

`TeamsApi`: данные на команду, статус игрока, дела и пинги от модов; `TeamCards.Detailed` с подписью и полосой. `Type.Weight.DISPLAY` (Space Grotesk для заголовков), токены колонок и источников ленты, `Kit.tooltip`, заглавные подписи. `ui.Kit`: шапка окна, кнопки, вкладки, вкладки-фильтры, счётчик, переключатель, плашки и `Kit.Hits` для нажимаемых мест. Окна без своего макета строятся из этих элементов.

## 1.4.0

Текст по макетам: `ui.Type` рисует Inter 400, 500 и 600 в пикселях экрана, `Draw.label` принимает кегль макета. В темах Slate и Glass шрифт `ryscore:inter`, `Draw.text` и `Draw.width` работают в нём сами. Измерять текст только через `Draw.width`, `Draw.widthScaled`, `Draw.labelWidth`: шрифт игры даёт другую ширину. `ui.Field` поле ввода с чипами, `ui.Icons` гладкие значки, `Theme.cells`, `slotRounded`. Радиусы считаются как макет ÷ 2, тень как в макете. Inter распространяется по SIL OFL 1.1.

## 1.3.0

`team.TeamCards`: карточки сводки на экране команды. Запасные токены `hud.fg` и `tooltip.fg` (запрос RYSQuests).

## 1.2.0

`team.TeamsApi`: команды для модов семьи. Без RYSTeams каждый игрок соло, его команда это его UUID. Подписка на вступление, уход, распад и слияние с предпросмотром и откатом.

## 1.1.0

Вид приведён к макетам. `Theme`: `sidebar`, `slots` (много ячеек одним вызовом через новый `ui.Tiles`), `slot` с рамкой состояния, `tabLine`, `tabLineFg`, поля `lineTabs`, `flushSidebar`. `Draw`: `magnifier`, `cross`, `star`, `dot`, мягкая тень без ступенек. Токены `slot.have.border`, `slot.miss.border`, метрики `tab.style: underline`, `sidebar.flush`. В Slate активные вкладки больше не янтарные: акцент оставлен главным действиям.

## 1.0.0

Первая версия, перенесено из RYScope: `Theme`, `ThemeManager`, `Draw`, `Loading`, темы Slate, Vanilla, Glass. Папка тем теперь `ryscore_themes`, выбор темы общий для всех модов: `config/ryscore/theme.json`.
